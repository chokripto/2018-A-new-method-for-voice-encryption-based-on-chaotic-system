# 2018-A-new-method-for-voice-encryption-based-on-chaotic-system

information security has become paramount since the human being need to exchange information. It
has developed over time from the Egyptians through the Greeks and Arabs to date. Researchers are
developing systems that provide their users with a perfect communication security. One of these systems
is one-time pad (OTP). It is considered as a secure encryption system, but it requires the use of a one-time
key having the same size as, or longer than, the message being sent, and the key is totally random.
In this presentation, we introduce a new pseudo-random bit generator. After a study of the chaotic
Gingerbreadman system, we managed to modify the system, to make the most of its properties by
avoiding fixed points. The Lyapunov exponent of the new system is positive, which means that the
system purely sensitive to the initial condition. The simulation analysis indicates that our PRNG has
exelent properties, it is sensitive to a small change in the key, and has successfully pass NIST of tests.
As an illustrative example, a new audio encryption method based on OTP and MGCS is discussed
